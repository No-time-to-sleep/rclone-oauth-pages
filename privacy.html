Privacy policy

Last updated: October 19, 2026

This application is a personal backup tool operated by its owner. It accesses the owner's Google Drive only to upload and manage backup copies of the owner's files.

What data is accessed

File names, file contents, and the folder structure of the Google Drive account that authorizes the application. The application may create, update, and delete files inside the backup folder it manages.

How data is used

Data is used solely to create and maintain backups. It is stored in the owner's own Google Drive. No data is sent to the developer or to any third party.

Credentials

OAuth tokens are stored locally on the owner's computer in rclone's configuration file and are not transmitted anywhere except to Google's OAuth and Drive APIs.

Data sharing

No personal data is sold, shared, or disclosed to third parties.

Contact

This application is for personal use. For questions, contact the owner of the Google Cloud project.
